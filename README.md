# FinGuard
Final project in Data Engineering course 2026 with NovaData

## Финтех-платформа «FinGuard»: мониторинг транзакций и выявление подозрительного поведения
Прототип  аналитической платформы, которая в режиме, близком к реальному времени, собирает финансовые транзакции и позволяет обнаруживать аномальное поведение клиентов (ФРОД).

## Стек технологий

* **Источники:** PostgresSQL, Kafka
* **Хранилище и обработка:** ClickHouse, PySpark
* **Оркестрация:** Airflow
* **Визуализация:** Grafana
* **Объектное хранилище:** MinIO 
* **Инфраструктура:** Docker

## Разделы проекта

- **Часть I.** Генератор данных с построением поведенческих профилей.
- **Часть II.** Создание справочников в PostgresSQL.
- **Часть III.** Публикация в Кафку.
- **Часть IV.** Запись в Clickhouse RAW.
- **Часть V.** Построение витрины в Clickhouse MART и Quarantine.
- **Часть VI.** Расчет признаков и клиентского риск-профиля.
